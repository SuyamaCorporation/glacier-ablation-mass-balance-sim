# 氷河 融解速度 マスバランス シミュレーション

気温・降雪量・アルベドのスライダーで氷河の年次マスバランスを計算し100年シミュレーション。

## 機能
- 気温変化（-2〜+6°C）・年間降雪量（500〜2000mm）・アルベド（0.3〜0.9）スライダー
- IPCCシナリオプリセット: SSP1-2.6/SSP3-7.0/SSP5-8.5/現状維持
- マスバランス時系列グラフ（100年）
- 氷河体積変化棒グラフ（色で体積変化を可視化）
- 年間蓄積量・融解量・バランス・消滅予測年表示
- 簡略化された物理式（蓄積モデル＋アルベドフィードバック）

## 技術
- 静的SPA（単一index.html）
- Tailwind CSS CDN
- Canvas（高DPIスケーリング対応）
- localStorage不使用
